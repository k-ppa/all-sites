## <ins>[Clicker](https://k-ppa.github.io/all-sites/Clicker/)</ins>

A tally counter website that I made

### Features

- Dark mode  
  Toggle dark mode using the button on the right side of the top header.
- Interval/Step value  
  Change the step value using the slider in the side-menu (-5 to +5).  
  The counter increses by increments of the selected step value.
- Target  
  Enter the target number in the input in the side-menu.  
  The counter will become green if it matches the target, and will become red if it exceeds the target.
- Measure speed  
  Turn on this mode by pressing the button in side-menu  
  This mode measures your best and average click speed (CPS) and keeps a history of them using `localStorage`. Its not yet ready (Haven't started making it)
